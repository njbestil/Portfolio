# Personal Portfolio

A responsive personal portfolio website built to showcase my professional background, technical skills, experience, and selected software development projects.

The website provides recruiters, clients, and potential collaborators with a clear overview of my work, capabilities, and experience as a software developer.

## Live Demo

View the deployed website:

**[njbestil.github.io/Portfolio](https://njbestil.github.io/Portfolio/)**

## Features

* Responsive design for desktop, tablet, and mobile devices
* Professional introduction and personal profile
* Technical skills overview
* Work experience and background
* Selected software development projects
* Project descriptions and technology details
* Contact and social media links
* Reusable React components
* Clean interface styled with Tailwind CSS

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/)
* npm

### Installation

1. Clone the repository:

```bash
git clone https://github.com/njbestil/Portfolio.git
```

2. Navigate to the project directory:

```bash
cd Portfolio
```

3. Install the project dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

Open the local address displayed in the terminal to view the application.

## Build for Production

Create an optimized production build:

```bash
npm run build
```
